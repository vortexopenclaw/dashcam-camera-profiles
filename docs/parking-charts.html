All measurements and advanced selection

Every source measurement remains available. Advanced selection can keep multiple tests per model.

Default test choice keeps a compatible selected test. Otherwise it uses the highest documented channel count, prefers established tests over provisional, superseded, or prototype tests, then uses the most recent known source date and a stable ID. For low-power parking, impact-sleep tests take priority over radar at the same channel count, and documented Power Saving modes take priority over Quick Start. Power draw does not determine the choice. Unknown dates are not evidence of a newer test.

Read the comparison in context

Current comparisons use one known test voltage. Use watts when comparing tests at different voltages.

Recording delay after impact detection and impact to the first recorded frame are separate methods. Unknown startup methods are not plotted as either metric. Missing data is excluded, never treated as zero.

A range shows only its measured endpoints, not an average. A zero measurement stays at the baseline. Source precision is retained, and power marked approximately was derived in the source dataset.
