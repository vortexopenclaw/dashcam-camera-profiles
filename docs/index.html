HOW TO READ THIS REFERENCE

Every claim keeps its evidence boundary.

Profiles combine sanitized card observations, official documentation, and measured technical samples. They preserve what each source establishes instead of filling gaps from a related product.

A product name is not a configuration

Resolution, frame rate, HDR, quality mode, firmware, and which cameras were connected can change how a dashcam records. A measured row describes that captured setup only. It does not predict every setting or revision of the same model.

Card-validated

A privacy-safe scan of a real card confirmed the listed storage behavior.

Manual-backed

Official documentation supports the claim, but a real card has not confirmed it yet.

Technical sample

A measured video fact is available, while the camera’s folder and filename behavior remains incomplete.

Catalog hint

The model is identified, but this reference does not claim its storage layout or recording behavior.

Evidence level is a scope label, not a product rating. Empty sections mean the project has not established that fact.
