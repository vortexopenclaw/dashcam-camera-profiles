FUNCTION, NOT MARKETING NAME

What stays awake matters.

“Low power” and “parking mode” do not describe one recording behavior. The categories below describe functionality; each measurement retains the source’s mode name.

Impact-triggered sleep

Wakes after an impact. No pre-event recording while asleep; wake delay can miss the incident. Low standby power is a different tradeoff, not a win over buffered recording.

Event detection

Buffered event modes retain footage before a trigger. Unbuffered event modes start after detection. Monitoring and active event recording can draw different power.

Ongoing recording

Time-lapse captures frames throughout the parked period. Low-bitrate modes record continuously at reduced bitrate. Neither is asleep waiting for an impact.

Radar can detect an approaching subject; hybrid behavior depends on the configuration. Check the source for buffering and trigger behavior. Unknowns stay unknown.
